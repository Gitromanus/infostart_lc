# Инфостарт Курс SM

Браузерное расширение для отслеживания курса и транзакций внутренней валюты $m на портале Infostart.ru.

## Описание

Расширение автоматически обновляет курс внутренней валюты $m с биржи Infostart, отображает статистику транзакций в рублях и $m, а также предоставляет удобный дашборд для мониторинга финансовых операций с AI-прогнозом дохода и статистикой по публикациям.

## Возможности

- **Автоматическое обновление курса**: актуальный курс $m с биржи Infostart
- **Дашборд статистики**: суммы за сегодня, месяц и общий итог ($m и ₽)
- **Конвертация валют**: пересчёт по текущему курсу
- **График дохода**: по дням / месяцам
- **AI-прогноз дохода**: адаптивные веса, акцент на текущий темп
- **Статистика по публикациям**: ТОП-10 и детальная таблица со ссылками
- **Фоновые уведомления**: курс и покупки через `chrome.alarms`
- **Telegram**: уведомления в Telegram (Bot Token + Chat ID)
- **Chrome-уведомления**: можно отключить, чтобы не дублировать с Telegram
- **Догрузка истории**: загрузка нескольких страниц транзакций
- **Фильтрация**: только операции из колонки «Приход» (Расход не учитывается)
- **Гибкое отображение**: скрытие прогноза и топа публикаций

## Установка

1. Скачайте архив из [Releases](https://github.com/Gitromanus/infostart_lc/releases) (`infostart_lc_v1.6.zip`)
2. Распакуйте в любую папку
3. Откройте `chrome://extensions/`
4. Включите «Режим разработчика»
5. «Загрузить распакованное расширение» → выберите папку

## Использование

### Статистика

- Страница транзакций: https://infostart.ru/profile/money/transact/
- Вверху появляется дашборд
- ⚙️ — настройки

### Уведомления

**О чём уведомлять:** повышение / понижение курса (с порогом %), покупки.

**Куда отправлять:**
- Chrome — системные уведомления браузера
- Telegram — сообщения от вашего бота

Если выключены и Chrome, и Telegram — уведомления не приходят.

### Настройка Telegram

1. [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте **token**
2. [@userinfobot](https://t.me/userinfobot) → получите **Chat ID**
3. В настройках: включите Telegram → вставьте token и Chat ID → Сохранить
4. Нажмите «Проверить уведомления»
